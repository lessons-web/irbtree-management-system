# 项目背景与目标

### 项目背景

针对悉尼 UNSW 学生，线下 CS 机构（如红黑树等）线下学员管理依赖 Excel 等分散工具，导致教务人员查询信息费力、缴费与课程权限脱节；同时，学员的刷题、模考与课件学习体验割裂，教学资产无法有效沉淀。

## 系统用户角色

1. **访客 \(Visitor\)：** 未登录用户，浏览公开信息。

2. **学生 \(Student\)：** 注册并登录的用户，消费课程内容。

3. **教师 \(Teacher\)：** 注册并登录的用户，维护课程信息。

4. **管理员 \(Admin\)：** 教务/教师，管理学员、财务与内容。

### 业务目标 \(V1\.0\)

- **核心目标：** 彻底替代 Excel，实现学员信息、缴费记录与课程权限的一体化管理，大幅提升教务运营效率。

- **次要目标：** 为学生提供统一的线上学习入口（课件、刷题、固定模考），完成教学资产的初步线上化沉淀。

- **成功指标：** 9月1日上线后，教务人员 100% 迁移至系统进行学员管理；核心课程内容（如 COMP9021/9024）完成线上化录入。

# 核心业务流程

**新生报名与开通流程：**

1. 学生在前端使用邮箱注册账号。

2. 学生通过线下/微信完成缴费。

3. 管理员在后台搜索该学生账号 \-\> 录入缴费记录 \-\> 手动开通对应课程权限并设置有效期。

4. 学生刷新 Dashboard，看到课程已开通，开始学习。

# 功能需求详情

### 管理端 \(Admin\) \- 核心重头戏

#### 学员管理模块 \(替代 Excel 的核心\)

- **学员列表：** 支持按邮箱、姓名、手机号、课程名称、权限状态（生效中/已过期）进行组合检索与分页展示。

- **学员详情页（360度视图）：**

    - **基础信息：** 姓名、邮箱、注册时间。

    - **课程与权限：** 展示已开通课程列表。支持手动添加/移除课程，支持设置绝对有效期（如 2026\-12\-31）或相对有效期（如自今日起 90 天）。

    - **跟进备注（时间轴）：** 支持管理员添加文本备注（如“26年6月3日：催收尾款，承诺下周交”），按时间倒序排列，记录操作人。

- **财务记录管理：**

    - 在学员详情页支持手工录入缴费流水：金额、币种（AUD/CNY）、支付方式（微信/银行转账）、关联课程、经手人、备注。

    - 财务状态（未付/部分付款/已付全款）由管理员手动标记，作为查账依据。

#### 内容与题库管理模块

- **课程与课件管理：** 创建课程，上传课件（支持 PDF 链接或外链），按周次/章节分类。

- **题库管理（手动录入）：**

    - 录入题目：题干（富文本）、知识点标签、难度（简单/中等/困难）、正确答案与解析（富文本）。

    - 附件支持：针对 COMP9021 等课程，支持上传 `.py` 模板文件供前端下载。

- **模考管理（固定试卷）：**

    - 创建试卷：填写试卷名称、限时时长（如 120 分钟）。

    - 手动选题：从题库中勾选题目加入试卷，设定每题分值。

### 学生端 \(Student\) \- 极简体验

#### 账号与基础模块

- **注册/登录：** 仅支持邮箱\+密码。必须包含基础防爆破机制（如连续错误 5 次锁定账号 15 分钟）。

- **找回密码：** 邮箱接收验证码重置密码。

- **Dashboard \(学习中心\)：**

    - 登录后展示“我的课程”。

    - 若无权限，展示清晰的“尚未开通课程，请联系教务微信 XXXXX 开通”的引导。

    - 若课程过期，锁定入口并提示续费。

#### 学习与刷题模块

- **课件浏览：** 列表展示按周次排列的课件，点击后在新标签页打开（鉴权拦截，防盗链）。

- **自由刷题区：**

    - 支持按“知识点标签”、“难度”筛选题目。

    - 题目详情页：展示题干、下载 `.py` 模板按钮。

    - 交互闭环：点击“查看解析”后，直接展示正确答案与解析（V1\.0 不做前端答题框，学生在本地 IDE 写代码，自己看解析对答案）。

    - 错题本：支持学生手动点击“加入错题本”，方便后续集中回顾。

#### 模考模块

- **模考流程：**

    - 列表展示可用模考，点击“开始”进入倒计时页面。

    - 页面顶部悬浮倒计时，展示题目列表。

    - V1\.0 简化交卷逻辑：学生在本地作答，倒计时结束后或主动交卷后，系统直接展示整套试卷的**所有正确答案与解析**。

    - **妥协说明：** 由于不支持自动判题，V1\.0 模考不产生系统自动计算的“得分”，由学生根据解析自行评估（大幅节省开发工作量）。

### 访客端 \(Visitor\)

- **首页/落地页：** 静态展示平台价值、课程卖点、适合人群。

- **公开课体验：** 提供 1\-2 节免费公开课件或样题的免登录访问入口，用于引流。

# Further Notes

鉴于 V1\.0 开发资源和时间的限制，特制定以下边界，**严禁在 V1\.0 阶段发生需求蔓延**：

1. **题库功能：** 管理系统完成后再进行开发，目前可以静态展示。后续支持手动录入（Markdown）**暂不**支持 Markdown 批量导入。

2. **模考组卷：** 仅支持管理员在后台手动组建“固定试卷”，**暂不**支持按标签/难度随机组卷。

3. **代码运行：** 纯文本展示与本地模板下载，**绝对不**包含任何在线运行（Online Judge）或自动判题功能。

4. **支付闭环：** 仅支持后台手工录入缴费记录，**暂不**接入微信/支付宝等在线支付接口。
