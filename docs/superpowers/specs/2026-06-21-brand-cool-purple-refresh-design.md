# brand 冷蓝紫主题色刷新设计

## 背景

项目已经完成了主色命名统一，组件层现在统一消费 `brand-*`。但当前 `brand` 色阶仍基本沿用旧的 `indigo` 观感，导致主题入口虽然已经抽离完成，整站视觉却没有形成用户期望中的“新紫色主色”感知。

用户已经明确希望把 `brand` 整套替换为新的紫色主色，并确认方向为“偏冷蓝紫”。

本次工作的重点不是继续调整类名体系，而是在不改动组件调用方式的前提下，直接刷新 `brand` 色板，让整站主按钮、导航激活态、输入框 focus、高亮浅底和渐变起点同步呈现新的冷蓝紫观感。

## 目标

- 将 `src/index.css` 中的 `brand-50` 到 `brand-950` 替换为新的冷蓝紫色板
- 保持所有组件继续使用现有 `brand-*` 类名，不新增第二套命名
- 让导航 active、按钮、focus ring、浅底高亮和品牌渐变形成可感知的视觉升级
- 保持系统仍适合后台和教育场景，不走偏粉或过度营销化风格

## 非目标

- 不新增暗黑模式或多皮肤切换机制
- 不调整页面布局和组件结构
- 不重新设计语义色，如 `red`、`yellow`、`emerald`
- 不再回退到 `indigo`、`primary` 等双轨主题命名

## 方案选择

本次采用「偏冷蓝紫」方案。

### 备选方向

- 中性正紫
- 偏粉洋紫

### 选择原因

冷蓝紫更适合当前系统：

- 比旧的 `indigo` 更有“新主色”感知
- 比正紫更克制，适合长时间阅读和后台表单场景
- 比偏粉紫更稳重，不会削弱教育和管理系统的专业感

## 色板设计

### 设计目标

新的 `brand` 色板应满足以下视觉要求：

- `brand-50` 到 `brand-100` 用于柔和浅底，不发灰、不偏粉
- `brand-500` 到 `brand-600` 作为主按钮、主链接和激活态的核心色
- `brand-700` 到 `brand-900` 作为深色强调、标题和选中边界色
- 整体从浅到深保持冷感统一，避免中段突然偏红或偏灰

### 拟定色阶

本次采用以下色值：

- `brand-50`: `#f4f5ff`
- `brand-100`: `#eceeff`
- `brand-200`: `#d9ddff`
- `brand-300`: `#bbc2ff`
- `brand-400`: `#98a2ff`
- `brand-500`: `#7c84ff`
- `brand-600`: `#635bff`
- `brand-700`: `#5546f5`
- `brand-800`: `#4638c7`
- `brand-900`: `#372f92`
- `brand-950`: `#241f63`

### 视觉预期

替换后应出现以下变化：

- 顶部导航 active 的描边和文字颜色更偏冷紫，识别度更高
- 主按钮颜色更鲜明，hover 后仍保留统一的冷感
- 输入框 focus 边框与 ring 的冷紫感更明确
- `brand-50` / `brand-100` 的背景块更有品牌识别，而不是旧的通用紫蓝

## 影响范围

本次主要影响一个文件：

- `src/index.css`

间接影响所有消费 `brand-*` 的页面和组件，包括：

- 用户端 Header、登录、推荐、课程详情、个人中心
- 后台表单、按钮、选中态和 focus 态
- 使用 `brand` 渐变的营销或推荐区块

## 兼容策略

组件层不做额外修改，继续沿用：

- `bg-brand-*`
- `text-brand-*`
- `border-brand-*`
- `ring-brand-*`
- `from-brand-*` / `to-brand-*`

这样可以保证主题切换仍然只有一个入口，即 `src/index.css` 中的 `brand` token。

## 风险与处理

### 风险 1：局部对比度不足

处理方式：

- 让 `brand-600` 明显强于旧值，确保按钮和导航激活态不会发灰
- 保留 `brand-900` / `brand-950` 足够深，保证深色文字和边界层级

### 风险 2：浅底提示块过于抢眼

处理方式：

- 控制 `brand-50` / `brand-100` 的饱和度，优先柔和而非荧光感

### 风险 3：品牌渐变区块过亮

处理方式：

- 先只刷新色板，不改单独组件
- 如果局部渐变显得太跳，再针对单个页面做微调，而不是回退整套主题

## 验证方案

实现阶段至少验证以下内容：

- `src/index.css` 中的 `brand` 色阶已替换为新的冷蓝紫值
- 主题一致性测试继续通过
- 构建继续通过
- 编辑过的文件无新增诊断问题
- 用户端导航 active、主按钮、focus ring 和浅底 `brand` 区块在视觉上有明显变化

## 实施顺序

建议按以下顺序执行：

1. 更新 `src/index.css` 中的 `brand-50` 到 `brand-950`
2. 如有需要，同步更新测试中的期望色值
3. 运行主题测试与全量测试
4. 运行构建并检查诊断
