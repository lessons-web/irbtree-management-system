# Admin Layout 侧栏简化与课程中心直达设计

## 背景

当前后台布局已经具备完整的侧栏、Header 和多业务页路由，但从实际界面表现看，左侧导航仍存在三类问题：

- Sidebar 顶部品牌区高度与右侧 Header 不一致，导致左右两侧顶部基线不齐
- 左侧菜单仍带有圆角卡片感和半透明背景，不符合用户希望的纯白、直角后台导航风格
- `课程中心` 仍被建模为带二级菜单的分组，而当前实际诉求是把它收敛为一级直达入口，默认直接进入课程列表

本次工作的目标不是重做后台信息架构，而是在保留现有后台壳层能力的前提下，收敛侧栏视觉样式和导航语义，让后台首页入口、菜单层级和整体布局更贴近目标稿。

## 目标

- 让 Sidebar 顶部品牌区高度与右侧 Header 保持一致
- 将左侧 Sidebar 调整为纯白背景、直角菜单、弱卡片感的后台导航风格
- 保留当前整栏折叠能力
- 将 `课程中心` 改为一级直达菜单，默认进入课程列表
- 下线 `课程关系视图`，同时移除对应侧栏入口和路由挂载

## 非目标

- 不调整 `评课管理`、`学员管理`、`题库管理`、`系统管理` 的业务边界
- 不新增按分组展开/收起的二级折叠交互
- 不改动用户端页面
- 不接入真实后台 API
- 不借机重构后台页面内容区、表格字段或 CRUD 逻辑

## 验收口径

本次改造完成后，应满足以下结果：

- 左侧品牌区与右侧 Header 形成统一的 64px 顶部高度
- Sidebar 整体为纯白背景，一级菜单与二级菜单都不再出现圆角胶囊或圆角卡片容器
- 侧栏仍支持当前的整栏折叠与展开
- `课程中心` 在左侧仅显示为一级菜单项，点击后直接进入课程列表
- 后台默认入口 `/admin` 和 `/admin/course-center` 都直接落到课程列表
- `课程关系视图` 不再出现在菜单中，也不再保留独立可访问路由

## 设计原则

### 1. 信息架构最小变更

本次只修正 `课程中心` 的导航语义，不对其他后台分组做额外拆分或合并。已有后台业务页的路径前缀和导航归属尽量保持不变，降低回归成本。

### 2. 视觉收敛优先

重点解决当前侧栏的顶部不齐、圆角过重和分组卡片感过强问题。样式收敛优先于新增交互，避免为了“更灵活”引入额外复杂度。

### 3. 保留现有壳层能力

通知抽屉、管理员菜单、页面标题映射和整栏折叠能力保持不变。本次只调整壳层结构和导航配置，不重写后台框架。

### 4. 路由与导航语义一致

用户从左侧看到的导航层级，需要与实际页面入口语义保持一致。既然 `课程中心` 的唯一主入口是课程列表，就不再保留仅为历史结构服务的二级 children。

## 方案选择

本次采用「保留整栏折叠 + 收敛侧栏样式 + 课程中心一级直达」方案。

### 备选方案

- 保持当前侧栏结构，只调整视觉样式
- 增加每个一级菜单单独展开/收起能力

### 不采用原因

只改视觉而不改 `课程中心` 的结构，无法满足“一级菜单直达课程列表”的要求；而增加分组折叠会引入新的状态管理和交互复杂度，不符合本次最小变更原则。

因此，本次确定：

- 保留现有整栏折叠
- 不新增分组折叠
- 直接把 `课程中心` 从“带 children 的分组”收敛为“一级入口”

## 影响范围

本次主要影响以下文件：

- `src/admin/AdminLayout.tsx`
- `src/admin/config/navigation.ts`
- `src/admin/config/navigationGroups.ts`
- `src/app/router.tsx`
- `src/admin/pages/AdminDomainNavigation.test.tsx`
- `src/app/router.test.tsx`

其中：

- `AdminLayout` 负责侧栏、品牌区和 Header 对齐的壳层实现
- 导航配置文件负责菜单分组、默认跳转和页面标题映射
- 路由文件负责下线 `课程关系视图` 并收敛 `课程中心` 入口语义
- 测试文件负责覆盖新的菜单结构和默认路由行为

## 布局设计

### 顶部对齐

左侧 Sidebar 顶部品牌区与右侧 Header 统一为同一高度：

- 使用与 Header 相同的高度基准
- 品牌区内部仍保留 Logo、系统标题和副标题
- 折叠态下仍显示 Logo，但不再因为上下留白过大造成品牌区显得更高

该调整的核心是让左右两侧顶部边界对齐，而不是单独放大或缩小 Logo 本身。

### Sidebar 容器

Sidebar 容器样式收敛为更标准的后台导航外观：

- 侧栏整体背景改为纯白色
- 保留右侧分隔线，用于与主内容区分层
- 去掉当前偏浅灰、半透明的背景处理
- 侧栏底部版本区继续保留，但与整体白底风格保持一致

### 一级菜单

一级菜单保持图标 + 文案结构，但视觉由圆角胶囊改为直角列表项：

- 不再使用大圆角
- 激活态保留浅色背景和左侧状态条
- hover 态仅做轻微背景变化
- 折叠态下只显示图标，维持当前可识别性

### 二级菜单

仍保留存在 children 的分组二级菜单，但样式与一级菜单统一收敛：

- 去掉当前包裹二级项的圆角卡片容器
- 二级项改为直角列表样式
- 保留轻缩进关系，体现层级
- 激活态与一级项共用同一套低强调视觉语言

### Header

右侧 Header 功能保持不变，仅配合顶部对齐关系确认高度基准：

- 继续展示当前页面标题
- 继续保留通知按钮和管理员菜单
- 不在本次新增 Header 内的折叠按钮或导航切换逻辑

## 导航结构设计

### 课程中心

`课程中心` 调整为一级直达菜单：

- 左侧仅展示 `课程中心`
- 点击后直接进入课程列表
- 不再渲染 `课程列表` 二级菜单
- 不再渲染 `课程关系视图` 入口

### 其他分组

以下分组继续保持现有一级 + 二级结构：

- `评课管理`
- `学员管理`
- `题库管理`
- `系统管理`

它们本次只做样式收敛，不做层级语义调整。

## 路由设计

### 默认入口

后台默认入口保持课程列表作为首屏：

- `/admin` 跳转到课程列表
- `/admin/course-center` 直接承载课程列表语义

### 课程中心路由

`课程中心` 的路由口径调整为：

- 保留课程列表页面路由
- 移除 `课程关系视图` 页面路由
- 页面标题映射继续将 `课程中心` 和课程列表统一显示为 `课程列表`

### 下线路由

`课程关系视图` 按确认结果一并下线：

- 移除路由挂载
- 移除默认跳转引用
- 移除导航配置中的入口定义

本次下线以“彻底移除后台入口语义”为原则，而不是隐藏菜单后继续保留孤立页面。

## 共享组件设计

### `AdminLayout`

`AdminLayout` 维持当前组件职责，但需要做以下收敛：

- 统一 Sidebar 顶部品牌区与 Header 的高度
- 将侧栏背景改为白底
- 去掉一级菜单、二级菜单和二级容器的圆角样式
- 保留当前整栏折叠按钮和交互
- 保留页面标题、通知抽屉和管理员菜单逻辑

### 导航配置

导航配置层需要同步表达新的菜单语义：

- `课程中心` 不再带 `children`
- `课程中心` 的目标路径直接指向课程列表
- `课程关系视图` 从导航分组定义中移除
- 页面标题映射收敛到课程列表相关入口

## 风险与处理

### 风险 1：移除 `课程关系视图` 后影响已有测试或直链

处理方式：

- 同步移除对应路由与测试断言
- 保留课程列表作为稳定默认入口
- 将影响范围限制在后台导航与后台路由，不外溢到用户端

### 风险 2：去掉圆角后侧栏层级感不足

处理方式：

- 保留浅色激活态和左侧状态条
- 通过边框、缩进和留白维持层级，而不是依赖圆角卡片

### 风险 3：整栏折叠状态下一级直达入口识别度下降

处理方式：

- 继续保留一级菜单图标
- 让 `课程中心` 在折叠态下仍可通过激活态高亮识别当前所在分组

## 验证方案

实现阶段至少需要验证以下结果：

- Sidebar 顶部品牌区与右侧 Header 高度一致
- Sidebar 展开态为纯白底，一级和二级菜单均为直角样式
- Sidebar 折叠与展开仍可正常切换
- 点击 `课程中心` 后直接进入课程列表
- `/admin` 和 `/admin/course-center` 都能正确落到课程列表
- `课程关系视图` 的菜单入口、路由挂载和相关测试断言都已移除
- 其他后台分组仍能正确显示二级菜单并正常跳转

## 实施顺序

建议按以下顺序执行：

1. 调整导航配置，收敛 `课程中心` 为一级直达入口并移除 `课程关系视图`
2. 调整路由配置，删除对应页面挂载与默认跳转引用
3. 调整 `AdminLayout`，统一顶部高度并收敛侧栏样式
4. 更新后台导航与路由测试
5. 进行手动回归，确认折叠、跳转和标题映射行为正常
